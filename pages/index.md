# ARC Affective

**Program badań nad multimodalnym przetwarzaniem informacji o stanie afektywnym i poznawczym.**

Program koncentruje się na metodach analizy sygnałów, uczeniu maszynowym i adaptacyjnych systemach interakcji człowiek–komputer. Rozważane są m.in. fuzja informacji, odporność na brak modalności, personalizacja modeli oraz wdrożenia obliczeń brzegowych.

## Kierunki badawcze

| Obszar | Pytanie badawcze |
| --- | --- |
| Reprezentacje EEG | Jak zmienia się jakość modeli przy ograniczonym montażu i zmianie zbioru danych? |
| Fuzja multimodalna | Jak uwzględniać niepewność, asynchronię i brakujące sygnały? |
| Adaptacja długoterminowa | Jak rozpoznawać dryf modelu pomiędzy sesjami? |
| Analiza obrazu | Jak ograniczać retencję wrażliwych danych podczas analizy zachowania? |
| Kinematyka dłoni | Które cechy ruchu odpowiadają obciążeniu zadaniowemu? |
| Adaptacyjne gry | Jak oceniać skuteczność regulacji trudności z kontrolą niepewności? |
| Interakcja z robotem | Jak integrować interpretację zachowania i niezależne ograniczenia bezpieczeństwa? |
| Obliczenia brzegowe | Jak zapewnić powtarzalność działania przy utracie sygnałów i ograniczonej mocy obliczeniowej? |

## Stan badań

Powyższe kierunki są programem badań. Nie oznaczają zakończonych eksperymentów, walidacji aparatury ani potwierdzonej skuteczności modeli. Wnioski empiryczne wymagają odpowiednich danych, kontroli jakości i walidacji niezależnej od danych treningowych.

Badania i opracowanie metod: Politechnika Rzeszowska.
