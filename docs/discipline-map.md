# Scientific-discipline mapping (Poland, 2026)

All eight manuscripts are formulated as engineering or computer-science research. **Emotion, affect and cognitive load are application contexts and imperfect target constructs, not the scientific discipline of the paper.** Polish disciplines: *automatyka, elektronika, elektrotechnika i technologie kosmiczne* (AEEiTK), *informatyka techniczna i telekomunikacja* (ITiT), and *informatyka*.

| Paper | Primary scientific discipline | Engineering core and expected result |
|---|---|---|
| P01 | ITiT / informatyka | EEG representation learning, robustness under channel/domain shift |
| P02 | ITiT / informatyka | Multisensor fusion, uncertainty quantification, missing-data inference |
| P03 | ITiT / informatyka | Online learning, concept drift and algorithmic recalibration |
| P04 | ITiT / informatyka | Computer vision, private edge algorithms, latency/accuracy trade-off |
| P05 | AEEiTK / ITiT | Kinematic feature estimation, optical tracking and measurement quality |
| P06 | ITiT / informatyka | Adaptive game control policies and computational HCI |
| P07 | AEEiTK / ITiT | Robot interaction, safe supervisory control, multimodal command processing |
| P08 | AEEiTK / ITiT | Real-time acquisition, edge computing, fault-tolerant scheduling |

**Exclusion:** no manuscript is planned as a psychological intervention, psychiatric classifier, neurological diagnosis, clinical biomarker verification or population psychometrics. Primary endpoints should involve algorithmic quality, inference reliability, controller performance or systems behaviour.
